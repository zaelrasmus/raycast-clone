# F18 — Search Emoji & Symbols

Branch: `f18-emoji-symbols` (worktree `D:\Dev\lumen-emoji`, based on `main` f1b9ea0).
Reference: Raycast's *Search Emoji & Symbols* — a grid, a category dropdown,
*Frequently Used*, pins, and Ctrl+K actions (Copy Unicode, custom keywords, pin).

## Decisions taken

- Built-in view source, not an extension (the protocol is frozen, 7.37).
- Emoji are drawn with the system font (Segoe UI Emoji, flat Fluent) in v1.
  The layout matches the screenshot; only the glyph differs from Raycast's 3D.
- The grid cell keeps the glyph source separate, so Fluent 3D images can be
  added later without a layout change. The image pipeline is parked on
  `f18-fluent-images` (9be1466): 1,595 images at 128 px, 4.5 MB, build.rs pack.
  If revived: 256 px source resized on the CPU to the exact cell size (GPUI
  samples without mipmaps), skin tones ~19 MB, budget to 50 MB.
- Skin tones come free with the font: a preference, Raycast-style.
- Catalogue generated by `scripts/make-emoji.ps1`, committed.
